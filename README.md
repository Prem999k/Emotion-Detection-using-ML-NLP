# 💬 Emotion Detection using NLP & Machine Learning

## 📌 Project Overview

This project is an **NLP-based Emotion Detection System** that analyzes user input text and predicts the underlying emotion in real-time.

The system uses **Machine Learning (Logistic Regression)** along with **TF-IDF feature extraction**, and is deployed using **Streamlit** to provide an interactive user experience.

---

## 🌐 Live Demo

👉 https://emotion-detection-using-ml-nlp-premkumark.streamlit.app/

---

## 🎯 Objectives

* Build an emotion detection system using NLP techniques
* Convert textual data into numerical form using TF-IDF
* Train a Machine Learning model for classification
* Deploy the model using Streamlit
* Provide real-time predictions with confidence scores

## 🧠 Model / Algorithm Used

### 🔹 TF-IDF Vectorizer

* Converts text into numerical feature vectors
* Captures importance of words

### 🔹 Logistic Regression

* Supervised classification algorithm
* Efficient and performs well for text classification

## 🔄 Workflow

* Data Collection
* Data Cleaning & Preprocessing

  * Lowercasing
  * Removing punctuation & numbers
  * Stopwords removal
  * Lemmatization
* Feature Extraction using TF-IDF
* Label Encoding
* Model Training (Logistic Regression)
* Model Evaluation
* Deployment using Streamlit

---

## 📊 How It Works

1. User enters text
2. Text is preprocessed using NLP techniques
3. Converted into TF-IDF vector
4. Model predicts emotion
5. Displays:

   * Predicted emotion
   * Confidence score
   * Emoji representation
